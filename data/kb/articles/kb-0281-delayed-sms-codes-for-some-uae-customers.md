**Update, 12 February 2025, 4:40 PM:** This is resolved. Codes are arriving normally again.

Some customers in the UAE received their one-time passwords late, or not at all, because of a problem at one mobile operator. Codes sent by email and app approvals weren't affected.

If a code didn't arrive, wait before asking for a new one. Requesting several codes in a row can lock code requests for a while. See [Not receiving OTP codes](kb-0153).
